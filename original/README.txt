This directory contains the supporting material of "Absolute Binding Free Energies with OneOPES"

Structure:

bin/ contains the ancillary scripts used to setup parts of the system
HSP90/ contains the structure, topology, and plumed files for both the MetaDynamics and OneOPES calculations on HSP90
     OneOPES/
     MetaDynamics/
BRD4/ contains the structure, topology, and plumed files for both the MetaDynamics and OneOPES calculations on BRD4
    OneOPES/
    MetaDynamics/
equilibration/ contains what is needed to equilibrate the given systems, and also contains a README.txt file with further instructions
